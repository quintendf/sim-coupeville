# Coupeville

An isometric sim of Coupeville, WA, built with Phaser 3, Vite, and TypeScript. Deploys to Vercel on every push to `main`.

- `npm install && npm run dev` to run locally.
- Town data (`public/data/town.json.gz`) is generated by `town_extract.py` (in the Agents Workspace, `Coupeville/data/scripts/`) from OpenStreetMap and USGS lidar. In production it loads from a Dropbox shared link so it can change without a deploy.
- Art: see `SPRITES.md` for the sprite contract.
- Full spec and history: `SPEC.md` in the Agents Workspace `Coupeville/` folder.
